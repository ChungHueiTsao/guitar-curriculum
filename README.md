# 吉他新手課程地圖

給第一次教吉他新手的完整教學規劃，以圖解為主：從吉他構造與調音開始，逐步建立左右手基礎、看懂六線譜、彈熟常用和弦與節奏型，最終能自彈自唱一首完整歌曲。附上《晴天》（周杰倫）的和弦拆解與通用伴奏指法示範。

## 內容

- 8 階段教學路線圖（構造調音 → 姿勢手感 → 節奏拍感 → 讀譜認識 → 開放和弦 → 刷弦節奏 → 自彈自唱 → 延伸風格）
- 吉他構造標註圖、左手手指編號圖、按弦角度對照圖
- 節奏刷弦時間軸圖（基礎／交替／民謠搖滾）
- 六線譜結構圖
- 開放和弦圖鑑（C、G、Am、Em、D、A）與換和弦共同指技巧圖
- 分解和弦撥弦順序圖、F 大橫按和弦圖
- 建議練習曲目、常見問題
- 《晴天》和弦進行拆解（不含歌詞）
